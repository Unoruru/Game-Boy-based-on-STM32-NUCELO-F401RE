# Game Boy Based on STM32 NUCLEO-F401RE

A small embedded game project for the STM32 NUCLEO-F401RE board. The program runs a simple falling-object catcher game on a 128x64 SSD1306 OLED display, controlled with an analog joystick and organized with FreeRTOS tasks.

The player moves a basket along the bottom of the screen. Catching fruit increases the score, while catching a bomb ends the game. The onboard green LED provides feedback for game events.

## Features

- STM32F401RETx firmware generated with STM32CubeMX / STM32CubeIDE
- FreeRTOS CMSIS-RTOS v2 task structure
- 128x64 SSD1306 OLED display over I2C
- Analog joystick input using ADC1 with DMA
- Button input for pause, resume, and restart
- Onboard LED feedback through an RTOS message queue
- Optional SEGGER SystemView / RTT support files
- Included coursework report: `ELEC0152_CW2_Game_Boy.pdf`

## Hardware

Target board:

- ST NUCLEO-F401RE
- MCU: STM32F401RETx
- Core clock: 84 MHz, configured from HSI through PLL

External parts used by the application:

| Part | Connection | Notes |
| --- | --- | --- |
| SSD1306 OLED | I2C1 | 128x64 display, I2C address `0x3C` |
| OLED SCL | PB8 | I2C1_SCL |
| OLED SDA | PB9 | I2C1_SDA |
| Joystick X axis | PA0 | ADC1_IN0 |
| Joystick Y axis | PA1 | ADC1_IN1 |
| Joystick button | PA9 | GPIO input, active low in the game logic |
| Onboard LED LD2 | PA5 | Green LED event feedback |
| USART2 | PA2 / PA3 | 115200 baud serial port |

The NUCLEO user button B1 on PC13 is configured as an EXTI falling-edge input by CubeMX, but the gameplay code uses the joystick button on PA9.

## Software Architecture

The application code is mainly in `Game-Boy/Core/Src` and `Game-Boy/Core/Inc`.

| File | Purpose |
| --- | --- |
| `main.c` | HAL startup, peripheral initialization, ADC DMA startup, OLED and joystick initialization, SystemView setup, FreeRTOS kernel start |
| `freertos.c` | RTOS objects and tasks for input, game logic, and LED feedback |
| `gameobjects.c/.h` | Basket, falling object, spawning, movement, collision, and drawing logic |
| `joystick.c/.h` | Joystick data structure and helper functions for ADC/button reads |
| `adc.c` | ADC1 scan conversion with circular DMA for joystick axes |
| `i2c.c` | I2C1 configuration for the OLED display |
| `gpio.c` | LD2, B1, and PA9 GPIO configuration |
| `usart.c` | USART2 configuration |
| `Drivers/OLED` | SSD1306 display driver and fonts |
| `Middlewares/Third_Party/FreeRTOS` | FreeRTOS kernel and CMSIS-RTOS v2 wrapper |
| `Middlewares/Third_Party/SEGGER` | SEGGER RTT/SystemView support files |

### FreeRTOS Tasks

The project defines three main tasks in `freertos.c`:

| Task | Priority | Role |
| --- | --- | --- |
| `InputTask` | Above normal | Samples joystick ADC values from the DMA buffer, reads the button, and publishes input through a mutex-protected shared struct |
| `GameTask` | Normal | Runs the game loop, updates state, draws to the OLED, checks collisions, tracks score, and sends LED events |
| `LedTask` | Low | Waits on a message queue and blinks LD2 for fruit catches or bomb hits |

RTOS synchronization primitives:

- `DataMutex`: protects shared joystick data
- `ButtonSem`: signals button press events to the game task
- `LedQueue`: sends game event messages to the LED task

## Game Rules

- Move the basket left and right with the joystick X axis.
- Catch fruit to increase the score.
- Catching a bomb switches the game to the game-over state.
- Press the joystick button to pause/resume the game.
- Press the joystick button on the game-over screen to restart.

Objects spawn at random horizontal positions near the top of the display. Fruit is represented as a filled square; bombs are drawn as an X.

## Build and Flash

Recommended workflow:

1. Install STM32CubeIDE.
2. Clone this repository.
3. Open STM32CubeIDE and import or open `Game-Boy/Gameboy.ioc`.
4. If CubeIDE asks to migrate or regenerate code, keep user code sections enabled.
5. Build the project for the STM32F401RETx target.
6. Connect the NUCLEO-F401RE over ST-LINK.
7. Flash and debug from STM32CubeIDE.

The repository includes a `Game-Boy/Debug` directory with generated build files and a prebuilt `Gameboy.elf`. Those files were generated by STM32CubeIDE and may contain machine-specific absolute paths. If command-line builds fail, regenerate the project from `Gameboy.ioc` in STM32CubeIDE or update the linker script path in the generated makefile.

## Notes

- The OLED driver is configured in `Drivers/OLED/ssd1306_conf.h` for STM32F4, I2C1, `128x64`, and address `(0x3C << 1)`.
- ADC1 is configured for two 12-bit conversions with circular DMA into `adcValues[2]`.
- Joystick thresholds in `Basket_Update()` are currently `x < 1000` for left and `x > 3000` for right.
- The game uses `rand()` for object spawn position, speed, and fruit/bomb type. No random seed is currently set, so spawn patterns may repeat after reset.
- The source has SEGGER SystemView support included; `main.c` configures SystemView and initializes the SEGGER UART helper.
